# pixelundpapier

Begleitseiten zu den Unterrichtsmaterialien von **Pixel & Papier**.
Jedes Material trägt einen QR-Code, der auf die Seite seiner Einheit zeigt.

Die Seiten richten sich an die Lehrkraft, nicht an die Kinder: fertige Tafelbilder,
Anschauung zum Text, passende Übungen. Das Material bleibt analog, digital wird nur
die Vorbereitung.

| Reihe | Einheit | Adresse |
|---|---|---|
| Robotik ohne Roboter | 1, Können Roboter denken? | `robotik/1/` |
| Robotik ohne Roboter | Übung, Zahnputz-Algorithmus | `robotik/uebungen/zahnputz/` |

Keine Analytics, keine externen Skripte, kein Login, keine gespeicherten Eingaben.
